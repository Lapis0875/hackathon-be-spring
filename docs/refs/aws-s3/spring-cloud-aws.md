### Upload files with S3Template

Source: https://github.com/awspring/spring-cloud-aws/blob/v4.2.1/docs/src/main/asciidoc/s3.adoc

Shows S3Template upload methods for uploading files with and without metadata. The InputStream is provided by the caller; BUCKET is a placeholder for the bucket name.

```java
@Autowired
private S3Template s3Template;

InputStream is = ...
// uploading file without metadata
s3Template.upload(BUCKET, "file.txt", is);

// uploading file with metadata
s3Template.upload(BUCKET, "file.txt", is, ObjectMetadata.builder().contentType("text/plain").build());
```

### Set S3 object metadata and write with S3Resource

Source: https://github.com/awspring/spring-cloud-aws/blob/v4.2.1/docs/src/main/asciidoc/s3.adoc

Casts the resource to S3Resource to set object metadata (content type and server-side encryption) before writing.

```java
@Value("s3://[S3_BUCKET_NAME]/[FILE_NAME]")
private Resource s3Resource;
...
ObjectMetadata objectMetadata = ObjectMetadata.builder()
    .contentType("application/json")
    .serverSideEncryption(ServerSideEncryption.AES256)
    .build();
s3Resource.setObjectMetadata(objectMetadata);
try (OutputStream outputStream = s3Resource.getOutputStream()) {
    outputStream.write("content".getBytes(StandardCharsets.UTF_8));
}
```

### Write to S3 resource with WritableResource

Source: https://github.com/awspring/spring-cloud-aws/blob/v4.2.1/docs/src/main/asciidoc/s3.adoc

Shows how to write content to an S3 resource by casting it to WritableResource and using getOutputStream.

```java
@Value("s3://[S3_BUCKET_NAME]/[FILE_NAME]")
private Resource s3Resource;
...
try (OutputStream os = ((WritableResource) s3Resource).getOutputStream()) {
  os.write("content".getBytes());
}
```
