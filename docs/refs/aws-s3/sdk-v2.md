### Generate presigned S3 GetObject request

Source: https://github.com/aws/aws-sdk-java-v2/blob/2.57.3/docs/design/core/presigners/README.md

Creates an S3Presigner and generates a presigned GetObject request with a 15-minute signature duration, then extracts the presigned URL. Use this when you need a presigned URL for an S3 object.

```Java
S3Presigner s3Presigner = S3Presigner.create();
PresignedGetObjectRequest presignedRequest =
        s3Presigner.presignGetObject(r -> r.getObject(get -> get.bucket("bucket").key("key"))
                                           .signatureDuration(Duration.ofMinutes(15)));
URL URL = presignedRequest.url();
```

### Get S3Presigner from existing S3Client

Source: https://github.com/aws/aws-sdk-java-v2/blob/2.57.3/docs/design/core/presigners/README.md

Creates an S3Presigner from an existing S3Client instance, inheriting its region and credentials, similar to s3.utilities().

