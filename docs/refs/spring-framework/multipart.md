This snippet demonstrates handling complex multipart requests, typical in RESTful services, where different parts might contain structured data (like JSON metadata) and files. It uses the `@RequestPart` annotation to access individual multipart sections, which are then converted by an `HttpMessageConverter`. Validation can be applied to `@RequestPart` arguments.

}
--edt7Tfrdusa7r3lNQc79vXuhIIMlatb7PQg7Vp
Content-Disposition: form-data; name="file-data"; filename="file.properties"
Content-Type: text/xml
Content-Transfer-Encoding: 8bit
... File Data ...
```

	@PostMapping("/")
	public String handle(@RequestPart("meta-data") MetaData metadata,
			@RequestPart("file-data") MultipartFile file) {

	}

### @RequestPart Annotation

Source: https://github.com/spring-projects/spring-framework/blob/v7.0.5/framework-docs/modules/ROOT/pages/web/webmvc/mvc-controller/ann-methods/arguments.adoc

Provides access to a part in a multipart/form-data request. The part's body is converted with an HttpMessageConverter. Used for handling file uploads and form data.

```APIDOC
## Controller Method Arguments: @RequestPart

### Description
For access to a part in a `multipart/form-data` request, converting the part's body with an HttpMessageConverter.

### Annotation
- `@RequestPart`

### Parameters
- **value** (String) - Optional - Name of the request part (defaults to parameter name)
- **name** (String) - Optional - Alias for value
- **required** (boolean) - Optional - Whether the part is required (default: true)

### Usage Examples

#### Single File Upload
```java
@PostMapping("/upload")
public String uploadFile(@RequestPart("file") MultipartFile file) {
    String filename = file.getOriginalFilename();
    long size = file.getSize();
    return "uploaded: " + filename;
}
```

#### File with Form Data
```java
@PostMapping("/submit")
public String submitForm(@RequestPart("file") MultipartFile file,
                         @RequestPart("metadata") FormMetadata metadata) {
    return "file: " + file.getOriginalFilename() + ", title: " + metadata.getTitle();
}

public class FormMetadata {
    private String title;
    private String description;
    // getters and setters
}
```

#### Multiple Files
```java
@PostMapping("/upload-multiple")
public String uploadMultiple(@RequestPart("files") List<MultipartFile> files) {
    return "uploaded " + files.size() + " files";
}
```

#### Optional Request Part
```java
@PostMapping("/create")
public String create(@RequestPart("data") Data data,
                     @RequestPart(value = "attachment", required = false) MultipartFile attachment) {
    return attachment != null ? "with attachment" : "no attachment";
}
```

#### JSON Request Part
```java
@PostMapping("/api/submit")
public String submitApi(@RequestPart("json") User user,
                        @RequestPart("file") MultipartFile file) {
    return "user: " + user.getName() + ", file: " + file.getOriginalFilename();
}
```

### Handle Single File Upload with @RequestParam in Spring

Source: https://github.com/spring-projects/spring-framework/blob/v7.0.5/framework-docs/modules/ROOT/pages/web/webmvc/mvc-controller/ann-methods/multipart-forms.adoc

This snippet demonstrates how to handle a single file upload and a regular form field in a Spring MVC controller using the `@RequestParam` annotation. It shows how to access the uploaded `MultipartFile` and its bytes, and redirect based on the upload's success or failure. A `MultipartResolver` must be configured for this to work.

```java
	@Controller
	public class FileUploadController {

		@PostMapping("/form")
		public String handleFormUpload(@RequestParam("name") String name,
				@RequestParam("file") MultipartFile file) {

			if (!file.isEmpty()) {
				byte[] bytes = file.getBytes();
				// store the bytes somewhere
				return "redirect:uploadSuccess";
			}
			return "redirect:uploadFailure";
		}
	}
```

### @RequestParam Annotation

Source: https://github.com/spring-projects/spring-framework/blob/v7.0.5/framework-docs/modules/ROOT/pages/web/webmvc/mvc-controller/ann-methods/arguments.adoc

Provides access to servlet request parameters, including multipart files. Parameter values are converted to the declared method argument type. Optional for simple parameter values.

```APIDOC
## Controller Method Arguments: @RequestParam

### Description
For access to servlet request parameters, including multipart files. Parameter values are converted to the declared method argument type.

### Annotation
- `@RequestParam`

### Parameters
- **value** (String) - Optional - Name of the request parameter (defaults to parameter name)
- **name** (String) - Optional - Alias for value
- **required** (boolean) - Optional - Whether the parameter is required (default: true)
- **defaultValue** (String) - Optional - Default value if parameter not provided

### Usage Examples

#### Single Request Parameter
```java
@GetMapping("/search")
public String search(@RequestParam String query) {
    return "searching for: " + query;
}
// URL: /search?query=spring
```

#### Multiple Request Parameters
```java
@GetMapping("/filter")
public String filter(@RequestParam String category, @RequestParam int page) {
    return "category: " + category + ", page: " + page;
}
// URL: /filter?category=books&page=1
```

#### Optional Request Parameter with Default
```java
@GetMapping("/list")
public String list(@RequestParam(required = false, defaultValue = "10") int limit) {
    return "limit: " + limit;
}
// URL: /list or /list?limit=20
```

#### Request Parameter with java.util.Optional
```java
@GetMapping("/items")
public String getItems(@RequestParam Optional<String> sort) {
    String sortBy = sort.orElse("name");
    return "sorted by: " + sortBy;
}
```

#### Multipart File Upload
```java
@PostMapping("/upload")
public String upload(@RequestParam("file") MultipartFile file) {
    String filename = file.getOriginalFilename();
    long size = file.getSize();
    return "uploaded: " + filename;
}
```

#### Multiple Files
```java
@PostMapping("/upload-multiple")
public String uploadMultiple(@RequestParam("files") List<MultipartFile> files) {
    return "uploaded " + files.size() + " files";
}
```

### Note
Use of `@RequestParam` is optional for simple parameter values. See "Any other argument" for implicit parameter binding.
```

### Multipart Content

Source: https://github.com/spring-projects/spring-framework/blob/v7.0.5/framework-docs/modules/ROOT/pages/web/webflux/controller/ann-methods/multipart-forms.adoc

You can also submit multipart requests from non-browser clients in a RESTful service scenario. In such cases, where you might have a file along with other data like JSON, you can access individual parts of the multipart request using the `@RequestPart` annotation. This annotation allows you to bind specific parts of the multipart request to method parameters, providing fine-grained control over how different components of the request are processed.
