### ResponseEntity

Source: https://github.com/spring-projects/spring-framework/blob/v7.0.5/framework-docs/modules/ROOT/pages/web/webmvc/mvc-controller/ann-methods/responseentity.adoc

A `ResponseEntity<Resource>` can be returned for file content, copying the `InputStream` content of the provided resource to the response `OutputStream`. Note that the `InputStream` should be lazily retrieved by the `Resource` handle in order to reliably close it after it has been copied to the response. If you are using `InputStreamResource` for such a purpose, make sure to construct it with an on-demand `InputStreamSource` (for example, through a lambda expression that retrieves the actual `InputStream`). Also, custom subclasses of `InputStreamResource` are only supported in combination with a custom `contentLength()` implementation which avoids consuming the stream for that purpose.

### Stream Raw Data with StreamingResponseBody in Spring MVC

Source: https://github.com/spring-projects/spring-framework/blob/v7.0.5/framework-docs/modules/ROOT/pages/web/webmvc/mvc-ann-async.adoc

This snippet demonstrates using `StreamingResponseBody` to stream raw data directly to the HTTP response's `OutputStream`, bypassing message conversion. This approach is ideal for scenarios like file downloads or when fine-grained control over the output stream is required. The `writeTo` method is where the application writes its data.

	public StreamingResponseBody handle() {

			@Override

				// write...
			}
		};
	}

### Request Mapping > Security > RFD Prevention

Source: https://github.com/spring-projects/spring-framework/blob/v7.0.5/framework-docs/modules/ROOT/pages/web/webmvc/mvc-controller/ann-requestmapping.adoc

To mitigate reflected file download attacks, Spring MVC adds a `Content-Disposition:inline;filename=f.txt` header to response bodies prior to rendering. This header is added only when the URL path contains a file extension that is neither marked as safe nor explicitly registered for content negotiation. This approach suggests a fixed and safe download filename to the browser. However, developers should be aware that this can have side effects when URLs are typed directly into a browser. Applications with custom `HttpMessageConverter` implementations can explicitly register file extensions for content negotiation to prevent the header from being added for those extensions.
