### @RequestBody Annotation

Source: https://github.com/spring-projects/spring-framework/blob/v7.0.5/framework-docs/modules/ROOT/pages/web/webmvc/mvc-controller/ann-methods/arguments.adoc

Provides access to the HTTP request body. Body content is converted to the declared method argument type using HttpMessageConverter implementations.

```APIDOC
## Controller Method Arguments: @RequestBody

### Description
For access to the HTTP request body. Body content is converted to the declared method argument type by using HttpMessageConverter implementations.

### Annotation
- `@RequestBody`

### Parameters
- **required** (boolean) - Optional - Whether the body is required (default: true)

### Usage Examples

#### JSON Request Body
```java
@PostMapping("/users")
public String createUser(@RequestBody User user) {
    return "created user: " + user.getName();
}

public class User {
    private String name;
    private String email;
    // getters and setters
}
```

#### Request Body with Validation
```java
@PostMapping("/products")
public String createProduct(@Valid @RequestBody Product product) {
    return "created product: " + product.getName();
}
```

#### Optional Request Body
```java
@PutMapping("/items/{id}")
public String updateItem(@PathVariable Long id, @RequestBody(required = false) Item item) {
    return item != null ? "updated" : "no update";
}
```

#### Raw String Body
```java
@PostMapping("/log")
public String logData(@RequestBody String rawData) {
    return "logged: " + rawData;
}
```

#### Generic Type Body
```java
@PostMapping("/data")
public String processData(@RequestBody Map<String, Object> data) {
    return "processed " + data.size() + " fields";
}
```
```

Source: https://github.com/spring-projects/spring-framework/blob/v7.0.5/framework-docs/modules/ROOT/pages/web/webflux/controller/ann-requestmapping.adoc

This example demonstrates how to use `@RequestMapping` at the class level to define a base path for a REST controller and then use HTTP method-specific annotations like `@GetMapping` and `@PostMapping` at the method level to handle specific HTTP requests. It shows how to extract path variables and handle request bodies, creating a complete REST endpoint setup.

```java

	@GetMapping("/{id}")
	public Person getPerson(@PathVariable Long id) {
		// ...
	}

	@PostMapping
	@ResponseStatus(HttpStatus.CREATED)
	public void add(@RequestBody Person person) {
		// ...
	}
}
```

### @RequestBody > Validation

Source: https://github.com/spring-projects/spring-framework/blob/v7.0.5/framework-docs/modules/ROOT/pages/web/webmvc/mvc-controller/ann-methods/requestbody.adoc

You can use `@RequestBody` in combination with `jakarta.validation.Valid` or Spring's `@Validated` annotation to apply Standard Bean Validation to the deserialized object. By default, validation errors cause a `MethodArgumentNotValidException`, which is converted into a 400 (BAD_REQUEST) response. Alternatively, you can handle validation errors locally within the controller by including an `Errors` or `BindingResult` argument in your method signature, allowing for custom error handling and response generation.
