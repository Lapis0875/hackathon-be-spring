### Create PostgreSQL Container Instance

Source: https://github.com/testcontainers/testcontainers-java/blob/2.0.3/docs/modules/databases/postgres.md

Demonstrates how to start a PostgreSQL container instance from a Java application using the Testcontainers module. This example shows the basic setup for a PostgreSQL container.

```java
import org.junit.jupiter.api.Test;
import org.testcontainers.containers.PostgreSQLContainer;
import org.testcontainers.junit.jupiter.Container;
import org.testcontainers.junit.jupiter.Testcontainers;

@Testcontainers
public class PostgreSQLContainerTest {

    @Container
    static PostgreSQLContainer postgresqlContainer = new PostgreSQLContainer("postgres:9.6.8");

    @Test
    void testContainerCreation() {
        // The container is automatically started when the test class is instantiated
        // You can access its properties like JDBC URL, username, password, etc.
        String jdbcUrl = postgresqlContainer.getJdbcUrl();
        String username = postgresqlContainer.getUsername();
        String password = postgresqlContainer.getPassword();

        System.out.println("JDBC URL: " + jdbcUrl);
        System.out.println("Username: " + username);
        System.out.println("Password: " + password);
    }
}
```

### Start MySQL Container Instance (Java)

Source: https://github.com/testcontainers/testcontainers-java/blob/2.0.3/docs/modules/databases/mysql.md

Demonstrates how to initiate a MySQL container instance within a Java application using Testcontainers. This requires the Testcontainers MySQL module dependency.

```java
import org.junit.jupiter.api.Test;
import org.testcontainers.containers.MySQLContainer;

public class MySQLContainerTest {

    @Test
    void container() {
        try (MySQLContainer<?> mysql = new MySQLContainer<>("mysql:8.0.36")) {
            mysql.start();
            // Use the container, e.g., get JDBC URL
            String jdbcUrl = mysql.getJdbcUrl();
            System.out.println("JDBC URL: " + jdbcUrl);
        }
    }
}
```

### Postgres Module > Testcontainers JDBC URL

Source: https://github.com/testcontainers/testcontainers-java/blob/2.0.3/docs/modules/databases/postgres.md

Testcontainers offers special JDBC URLs for simplified database container usage. For PostgreSQL, the format is `jdbc:tc:postgresql:9.6.8:///databasename`. This format is also supported for specialized PostgreSQL distributions like PostGIS (`jdbc:tc:postgis:9.6-2.5:///databasename`), TimescaleDB (`jdbc:tc:timescaledb:2.1.0-pg13:///databasename`), and PGvector (`jdbc:tc:pgvector:pg16:///databasename`). More details on JDBC integration can be found in the [JDBC](./jdbc.md) documentation.
