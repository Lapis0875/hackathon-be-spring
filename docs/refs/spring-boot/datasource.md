### Configure H2 In-Memory DataSource Properties in YAML

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/how-to/pages/data-access.adoc

Sets up an H2 in-memory data source by defining its URL, username, and connection pool size within the `app.datasource` properties in YAML.

```yaml
app:
  datasource:
    url: "jdbc:h2:mem:mydb"
    username: "sa"
    pool-size: 30
```

### Configure HikariDataSource with `jdbc-url` Property in YAML

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/how-to/pages/data-access.adoc

Demonstrates configuring a HikariDataSource by using the `jdbc-url` property instead of `url`, along with username, password, and pool size, to correctly establish the database connection.

```yaml
app:
  datasource:
    jdbc-url: "jdbc:mysql://localhost/test"
    username: "dbuser"
    password: "dbpass"
    pool-size: 30
```

### Configure DataSource with `DataSourceProperties` and Hikari Pool Size

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/how-to/pages/data-access.adoc

Illustrates configuring a data source using `DataSourceProperties` for URL translation and setting Hikari-specific pool properties under a nested `configuration` key in YAML.

```yaml
app:
  datasource:
    url: "jdbc:mysql://localhost/test"
    username: "dbuser"
    password: "dbpass"
    configuration:
      maximum-pool-size: 30
```

### YAML Configuration for Production DataSource

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/reference/pages/data/sql.adoc

Configure production database connection properties in `application.properties` using YAML. Specifying `spring.datasource.url` is required to prevent embedded database auto-configuration.

```yaml
spring:
  datasource:
    url: "jdbc:mysql://localhost/test"
    username: "dbuser"
    password: "dbpass"
```
