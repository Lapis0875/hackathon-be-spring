### Handling Multipart File Uploads

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/how-to/pages/spring-mvc.adoc

Spring Boot supports file uploads using the Servlet 5 jakarta.servlet.http.Part API. By default, Spring MVC is configured with a maximum file size of 1MB per file and a total maximum of 10MB of file data per single request.

### Multipart support

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/how-to/pages/spring-mvc.adoc

Spring Boot's multipart support allows receiving multipart encoded file data as a MultipartFile parameter in Spring MVC controller handler methods. You can override properties like intermediate data storage location and disk flush threshold using the MultipartProperties class. It is recommended to use the container's built-in support for multipart uploads instead of adding external dependencies.
