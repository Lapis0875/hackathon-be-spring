### Data Initialization > Migration Tools > Execute Liquibase Database Migrations on Startup

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/how-to/pages/data-initialization.adoc

To automatically run Liquibase database migrations on startup, add the "spring-boot-starter-liquibase" starter to your classpath. By default, migrations run during application startup and before tests, a behavior customizable with "spring.liquibase.enabled". The master change log is read from "db/changelog/db.changelog-master.yaml" by default, but this can be changed using "spring.liquibase.change-log". Liquibase supports YAML, JSON, XML, and SQL change log formats.

### Data Initialization > Use a Higher-level Database Migration Tool > Execute Flyway Database Migrations on Startup

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/how-to/pages/data-initialization.adoc

To automatically run Flyway database migrations on startup, include the appropriate Flyway module in your classpath. Migrations are typically SQL scripts in `classpath:db/migration`, but this location can be customized using `spring.flyway.locations` to include multiple `classpath:` or `filesystem:` paths, or even vendor-specific directories using a `\{vendor}` placeholder.

### Data Initialization > Migration Tools > Execute Liquibase Database Migrations on Startup

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/how-to/pages/data-initialization.adoc

By default, Liquibase autowires the primary DataSource for migrations. To use a different DataSource, create a bean and mark it with "@LiquibaseDataSource". If retaining the main auto-configured DataSource, set the "defaultCandidate" attribute to "false" for the custom bean. Alternatively, Liquibase can use its own DataSource by setting "spring.liquibase.url" or "spring.liquibase.user" in external properties. Unset "spring.liquibase" properties will default to their "spring.datasource" equivalents.

### Data Initialization > Use a Higher-level Database Migration Tool > Execute Flyway Database Migrations on Startup

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/how-to/pages/data-initialization.adoc

Flyway migrations can be written in Java by implementing `JavaMigration`. Spring Boot provides `FlywayProperties` for configuration, and `FlywayConfigurationCustomizer` or `FlywayMigrationStrategy` beans can be registered for more advanced control over the migration process. Flyway also supports SQL and Java callbacks for custom logic during migration.

### Configure Flyway Migration Locations

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/how-to/pages/data-initialization.adoc

Specify a comma-separated list of classpath or filesystem locations where Flyway should search for migration scripts.

```yaml
spring:
  flyway:
    locations: "classpath:db/migration,filesystem:/opt/migration"
```
