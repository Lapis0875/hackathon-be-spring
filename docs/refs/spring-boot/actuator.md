### Expose All Actuator Endpoints (YAML)

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/reference/pages/actuator/endpoints.adoc

Configure `management.endpoints.web.exposure.include` to `*` to expose all web-based Actuator endpoints.

```yaml
management:
  endpoints:
    web:
      exposure:
        include: "*"
```

### Customize Actuator Base Path in YAML

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/reference/pages/actuator/monitoring.adoc

Use this configuration to change the default '/actuator' prefix for management endpoints to a custom path like '/manage'.

```yaml
  endpoints:
    web:
      base-path: "/manage"
```

### Exclude All Web Endpoints in YAML

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/reference/pages/actuator/monitoring.adoc

This configuration excludes all web-exposed Actuator endpoints, preventing them from being accessible.

```yaml
    web:
```

### Expose All Web Endpoints Except Env and Beans (YAML)

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/reference/pages/actuator/endpoints.adoc

Configures web exposure to include all endpoints using a wildcard, then explicitly excludes the 'env' and 'beans' endpoints.

```yaml
management:
  endpoints:
    web:
      exposure:
        include: "*"
        exclude: "env,beans"
```
