The @WebMvcTest annotation focuses on testing Spring MVC controllers by disabling full auto-configuration and scanning only controller-related components. It does not scan regular @Component or @ConfigurationProperties beans, though @EnableConfigurationProperties can be used to include the latter. This annotation is typically used for a single controller, often combined with @MockitoBean to provide mock implementations for collaborators.
