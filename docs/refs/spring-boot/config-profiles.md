Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/reference/pages/features/external-config.adoc

### Features > Profiles > Profile-specific Configuration Files

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/reference/pages/features/profiles.adoc

### Type-safe Configuration Properties > Using @ConfigurationProperties-annotated Types

Source: https://github.com/spring-projects/spring-boot/blob/v4.1.0/documentation/spring-boot-docs/src/docs/antora/modules/reference/pages/features/external-config.adoc

Using `@ConfigurationProperties`-annotated types integrates effectively with Spring Boot's external YAML configuration, allowing properties to be defined in a structured way. These configuration properties can then be injected into other beans in the same manner as any standard bean.
