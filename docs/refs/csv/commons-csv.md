### CSVFormat Builder: Get Header

Source: https://commons.apache.org/proper/commons-csv/jacoco/org.apache.commons.csv/CSVFormat.java.html

Use this to get a CSVFormat instance with headers automatically set from the first record. This makes code impervious to column order changes.

```java
CSVFormat.EXCEL.builder().setHeader().get();
```

### Parse CSV with custom column names and skip header

Source: https://commons.apache.org/proper/commons-csv/jacoco/org.apache.commons.csv/CSVFormat.java.html

### Set Header using String Array - CSVFormat Builder

Source: https://commons.apache.org/proper/commons-csv/apidocs/org/apache/commons/csv/CSVFormat.Builder.html

Sets the header to the given String values. This method keeps a copy of the input array and is also used by the CSVPrinter.

```java
builder.setHeader();
```

```java
builder.setHeader("name", "email", "phone");
```

### Create CSVPrinter with CSVFormat

Source: https://commons.apache.org/proper/commons-csv/jacoco/org.apache.commons.csv/CSVFormat.java.html

Creates a CSVPrinter instance to write CSV data to the specified Appendable output, using the current CSVFormat. This is the primary method for writing CSV data.

```java
public CSVPrinter print(final Appendable out) throws IOException {
    return new CSVPrinter(out, this);
}
```
