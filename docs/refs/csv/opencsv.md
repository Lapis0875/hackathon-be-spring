### Write beans to CSV with StatefulBeanToCsvBuilder

Source: https://opencsv.sourceforge.net/index.html

Writes a list of annotated beans to a CSV file. Requires a Writer and a list of beans. The builder creates a StatefulBeanToCsv, then write() outputs the beans and the writer is closed.

```java
     // List<MyBean> beans comes from somewhere earlier in your code.
     Writer writer = new FileWriter("yourfile.csv");
     StatefulBeanToCsv beanToCsv = new StatefulBeanToCsvBuilder(writer).build();
     beanToCsv.write(beans);
     writer.close();
```

### Read with iterator of annotated bean using CsvToBeanBuilder

Source: https://opencsv.sourceforge.net/xref-test/com/opencsv/bean/CsvToBeanAsIteratorTest.html

Uses a HeaderColumnNameMappingStrategy for MinimalCsvBindByNameBeanForWriting and a StringReader with CSV data, then iterates over parsed beans, asserting field values for two records.

```java
HeaderColumnNameMappingStrategy<MinimalCsvBindByNameBeanForWriting> minimalStrategy = **new** HeaderColumnNameMappingStrategy<>();
minimalStrategy.setType(MinimalCsvBindByNameBeanForWriting.**class**);
StringReader reader = **new** StringReader("finda,findb,c\n1,2,3\n4,5,6");
Iterator<MinimalCsvBindByNameBeanForWriting> iterator = **new** CsvToBeanBuilder<MinimalCsvBindByNameBeanForWriting>(reader)
        .withMappingStrategy(minimalStrategy)
        .build()
        .iterator();

assertTrue(iterator.hasNext());
MinimalCsvBindByNameBeanForWriting mockBean = iterator.next();
assertEquals(1, mockBean.getA());
assertEquals(2, mockBean.getB());
assertEquals(3, mockBean.getC());

assertTrue(iterator.hasNext());
mockBean = iterator.next();
assertEquals(4, mockBean.getA());
assertEquals(5, mockBean.getB());
assertEquals(6, mockBean.getC());

assertFalse(iterator.hasNext());
```
