===============
LIBRARY RULES
===============
From library maintainers:
- Use the FastCSV 4.x API: CsvReader.builder().ofCsvRecord(...) or .ofNamedCsvRecord(...) for reading, CsvWriter.builder().build(...) for writing.
- Always close CsvReader and CsvWriter, preferably with try-with-resources.
- Maven coordinates: de.siegmar:fastcsv. FastCSV 4.x requires Java 17+.
- Do not use APIs from FastCSV 1.x or 2.x (e.g. NamedCsvReader, CsvContainer); they no longer exist.
- FastCSV has no reflection-based bean mapping; map NamedCsvRecord to objects via Java streams (see the bean-mapping guide).
- FastCSV has no runtime dependencies; do not add other CSV libraries for basic reading or writing.



### Read CSV records with headers using NamedCsvRecord

Source: https://github.com/osiegmar/fastcsv/blob/main/docs/src/content/docs/guides/quickstart.mdx

Reads CSV records with headers and prints the value of the field named "foo" for each record. Uses CsvReader.builder().ofNamedCsvRecord(file).

```java
Path file = Path.of("input.csv");
try (CsvReader<NamedCsvRecord> csv = CsvReader.builder().ofNamedCsvRecord(file)) {
    csv.forEach(rec -> System.out.println(rec.getField("foo")));
}
```

### Usage

Basic usage of the `CsvWriter` is demonstrated below.

This very basic example hides all the complexity that is going on behind the scenes.

- The `CsvWriterBuilder` is instantiated with default settings by the `CsvWriter.builder()` factory method.
- The `build()` method opens the given CSV file, initializes the `CsvWriter`, and returns it to the user.
- The user writes a record to the CSV file by calling `writeRecord()` on the `CsvWriter`.
- As the `CsvWriter` also implements `AutoCloseable`, the user can rely on the wrapping try-with-resources statement to

### Write CSV records with CsvWriter

Source: https://github.com/osiegmar/fastcsv/blob/main/README.md

Writes two CSV records to a file named output.csv using the builder pattern. The try-with-resources block ensures the writer is closed automatically.

```java
try (CsvWriter csv = CsvWriter.builder().build(Path.of("output.csv"))) {
    csv
        .writeRecord("header 1", "header 2")
        .writeRecord("value 1", "value 2");
}
```
