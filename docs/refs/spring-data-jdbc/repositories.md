### Spring Data JDBC Repository Example

Source: https://github.com/spring-projects/spring-data-relational/blob/main/README.adoc

Quick teaser of an application using Spring Data JDBC Repositories in Java. Includes a Person entity, a PersonRepository with @Query methods, a MyService that uses the repository, and an ApplicationConfig with @EnableJdbcRepositories.

```java
@Table
public class Person {

    @Id
    private Long id;
    private String firstname;
    private String lastname;

    // getters and setters
}

interface PersonRepository extends CrudRepository<Person, Long> {

    @Query("SELECT * FROM person WHERE lastname = :lastname")
    List<Person> findByLastname(String lastname);

    @Query("SELECT * FROM person WHERE firstname LIKE :firstname")
    List<Person> findByFirstnameLike(String firstname);
}

@Service
class MyService {

    private final PersonRepository repository;

    public MyService(PersonRepository repository) {
        this.repository = repository;
    }

    public void doWork() {

        repository.deleteAll();

        Person person = new Person();
        person.setFirstname("Jens");
        person.setLastname("Schauder");
        repository.save(person);

        List<Person> lastNameResults = repository.findByLastname("Schauder");
        List<Person> firstNameResults = repository.findByFirstnameLike("Je%");
    }
}

@Configuration
@EnableJdbcRepositories
class ApplicationConfig extends AbstractJdbcConfiguration {

    @Bean
    public DataSource dataSource() {
        return …;
    }

     @Bean
     public NamedParameterJdbcTemplate namedParameterJdbcTemplate(DataSource dataSource) {
         return new NamedParameterJdbcTemplate(dataSource);
     }
}
```

### Declare a query method by using @Query

Source: https://github.com/spring-projects/spring-data-relational/blob/main/src/main/antora/modules/ROOT/pages/jdbc/query-methods.adoc

Use @Query to define a custom query. The query must match the format expected by the RowMapper, providing columns for all constructor properties. Properties set via setter, wither, or field access are optional. The query is used for populating the aggregate root, embedded entities, and one-to-one relationships.

```java
interface UserRepository extends CrudRepository<User, Long> {

    @Query("SELECT first_name, last_name FROM user WHERE email_address = :email")
    User findByEmailAddress(@Param("email") String email);
}
```

### Field-to-column name resolution

Source: https://github.com/spring-projects/spring-data-relational/blob/main/spring-data-relational/src/main/java/org/springframework/data/relational/core/mapping/BasicRelationalPersistentProperty.java

When a field has a @Column annotation, its value is used as the column name. Otherwise, the NamingStrategy converts camelCase field names to snake_case column names (e.g. `myField` → `my_field`).

```java
if (isAnnotationPresent(Column.class)) {

    Column column = getRequiredAnnotation(Column.class);
    this.hasExplicitColumnName = StringUtils.hasText(column.value());

    this.columnName = Lazy.of(() -> StringUtils.hasText(column.value()) ? createSqlIdentifier(column.value())
            : createDerivedSqlIdentifier(namingStrategy.getColumnName(this)));
    this.columnNameExpression = detectExpression(column.value());

    if (collectionIdColumnName == null && StringUtils.hasText(column.value())) {
        collectionIdColumnName = Lazy.of(() -> Optional.of(createSqlIdentifier(column.value())));
    }

} else {
    this.hasExplicitColumnName = false;
    this.columnName = Lazy.of(() -> createDerivedSqlIdentifier(namingStrategy.getColumnName(this)));
    this.columnNameExpression = null;
}
```

### Spring Data JDBC repositories using Java configuration

Source: https://github.com/spring-projects/spring-data-relational/blob/main/src/main/antora/modules/ROOT/pages/jdbc/getting-started.adoc

Java configuration class that enables Spring Data JDBC repositories using @EnableJdbcRepositories and extends AbstractJdbcConfiguration. It defines beans for DataSource, NamedParameterJdbcOperations, and TransactionManager.

```java
@Configuration
@EnableJdbcRepositories                                                                // <1>
class ApplicationConfig extends AbstractJdbcConfiguration {                            // <2>

    @Bean
    DataSource dataSource() {                                                         // <3>

        EmbeddedDatabaseBuilder builder = new EmbeddedDatabaseBuilder();
        return builder.setType(EmbeddedDatabaseType.HSQL).build();
    }

    @Bean
    NamedParameterJdbcOperations namedParameterJdbcOperations(DataSource dataSource) { // <4>
        return new NamedParameterJdbcTemplate(dataSource);
    }

    @Bean
    TransactionManager transactionManager(DataSource dataSource) {                     // <5>
        return new DataSourceTransactionManager(dataSource);
    }
}
```
