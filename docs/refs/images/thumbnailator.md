### Create JPEG thumbnails from directory files with Thumbnails.of

Source: https://github.com/coobird/thumbnailator/blob/master/README.md

Uses Thumbnailator's fluent interface to create JPEG thumbnails of all image files in a directory, resized to a maximum dimension of 640x480 pixels while preserving aspect ratio. The output files are prefixed with 'thumbnail.' using Rename.PREFIX_DOT_THUMBNAIL.

```java
Thumbnails.of(new File("path/to/directory").listFiles())
    .size(640, 480)
    .outputFormat("jpg")
    .toFiles(Rename.PREFIX_DOT_THUMBNAIL);
```

### Create a thumbnail and write to an OutputStream

Source: https://github.com/coobird/thumbnailator/wiki/Examples

Resizes large-picture.jpg to a maximum dimension of 200x200 (maintaining aspect ratio) and writes the result as a PNG to the specified OutputStream.

```java
OutputStream os = ...;

        .outputFormat("png")
```

### Create a thumbnail with rotation and a watermark

Source: https://github.com/coobird/thumbnailator/wiki/Examples

Resizes original.jpg to 160x160, rotates 90 degrees clockwise, adds a half-transparent watermark at the bottom-right, and saves with 80% compression quality.

```java
Thumbnails.of(new File("original.jpg"))
        .size(160, 160)
        .rotate(90)
        .watermark(Positions.BOTTOM_RIGHT, ImageIO.read(new File("watermark.png")), 0.5f)
        .outputQuality(0.8)
        .toFile(new File("image-with-watermark.jpg"));
```

### Create thumbnail to fit within size (Thumbnails.of().size().asBufferedImage())

Source: https://github.com/coobird/thumbnailator/wiki/Examples

Creates a thumbnail that fits within the specified 200x200 dimensions while preserving the aspect ratio. The resulting thumbnail may be smaller than the specified size if the source image's aspect ratio differs; for example, a 300x400 source produces a 150x200 thumbnail.

```java
BufferedImage originalImage = ImageIO.read(new File("original.png"));

BufferedImage thumbnail = Thumbnails.of(originalImage)
        .size(200, 200)
        .asBufferedImage();
```
