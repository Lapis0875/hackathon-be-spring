### JPEG

Source: https://github.com/haraldk/twelvemonkeys/wiki/JPEG-Plugin

* Read support for the following JPEG "flavors":
  * All JFIF compliant JPEGs
  * All Exif compliant JPEGs
  * YCbCr JPEGs without JFIF segment (converted to RGB, using embedded ICC profile)
  * CMYK JPEGs (converted to RGB by default or as CMYK, using embedded ICC profile)
  * Adobe YCCK JPEGs (converted to RGB by default or as CMYK, using embedded ICC profile)
  * JPEGs containing ICC profiles with interpretation other than 'Perceptual' or class other than 'Display'
  * JPEGs containing ICC profiles that are incompatible with stream data, corrupted ICC profiles or corrupted `ICC_PROFILE` segments
  * JPEGs using non-standard color spaces, unsupported by Java 2D
  * JPEGs with APP14/Adobe segments with length other than 14 bytes
  * 8 bit JPEGs with 16 bit DQT segments
  * Issues warnings instead of throwing exceptions in cases of corrupted or non-conformant data where ever the image 
  data can still be read in a reasonable way

### WebP - Google WebP format

Source: https://github.com/haraldk/twelvemonkeys/wiki/WebP-Plugin

# WebP - Google WebP format

* Read support for:
  * Lossy VP8 encoding
  * Lossless VP8L encoding (from 3.9)
  * Lossy WebP with lossless alpha (from 3.9)
  * Limited animation support (ie. frames can be read)

* Metadata support:
  * Standard metadata

### JPEG color space detection (CMYK/YCCK/unsupported)

Source: https://github.com/haraldk/twelvemonkeys/blob/master/imageio/imageio-jpeg/src/main/java/com/twelvemonkeys/imageio/plugins/jpeg/JPEGImageReader.java

Determines the JPEG source color space from JFIF/AdobeDCT/SOF markers. Returns CMYK or YCCK for 4-component Adobe images, and guesses from component IDs otherwise. Throws IIOException for frames with unsupported component counts.

```java
    static JPEGColorSpace getSourceCSType(final JFIF jfif, final AdobeDCT adobeDCT, final Frame startOfFrame) throws IIOException {
        switch (startOfFrame.componentsInFrame()) {
            case 1:
                return JPEGColorSpace.Gray;
            case 2:
                return JPEGColorSpace.GrayA;
            case 3:
                if (jfif != null) {
                    return JPEGColorSpace.YCbCr;
                }
                else if (adobeDCT != null) {
                    switch (adobeDCT.transform) {
                        case AdobeDCT.Unknown:
                            return JPEGColorSpace.RGB;
                        default:
                        case AdobeDCT.YCC:
                            return JPEGColorSpace.YCbCr;
                    }
                }
                else {
                    int cid0 = startOfFrame.components[0].id;
                    int cid1 = startOfFrame.components[1].id;
                    int cid2 = startOfFrame.components[2].id;
                    if (cid0 == 1 && cid1 == 2 && cid2 == 3) {
                        return JPEGColorSpace.YCbCr;
                    }
                    else if (cid0 == 'R' && cid1 == 'G' && cid2 == 'B') {
                        return JPEGColorSpace.RGB;
                    }
                    else if (cid0 == 'Y' && cid1 == 'C' && cid2 == 'c') {
                        return JPEGColorSpace.PhotoYCC;
                    }
                    else {
                        return JPEGColorSpace.YCbCr;
                    }
                }
            case 4:
                if (adobeDCT != null) {
                    switch (adobeDCT.transform) {
                        case AdobeDCT.Unknown:
                            return JPEGColorSpace.CMYK;
                        default:
                        case AdobeDCT.YCCK:
                            return JPEGColorSpace.YCCK;
                    }
                }
                else {
                    int cid0 = startOfFrame.components[0].id;
                    int cid1 = startOfFrame.components[1].id;
                    int cid2 = startOfFrame.components[2].id;
                    int cid3 = startOfFrame.components[3].id;
                    if (cid0 == 1 && cid1 == 2 && cid2 == 3 && cid3 == 4) {
                        return JPEGColorSpace.YCbCrA;
                    }
                    else if (cid0 == 'R' && cid1 == 'G' && cid2 == 'B' && cid3 == 'A') {
                        return JPEGColorSpace.RGBA;
                    }
                    else if (cid0 == 'Y' && cid1 == 'C' && cid2 == 'c' && cid3 == 'A') {
                        return JPEGColorSpace.PhotoYCCA;
                    }
                    else {
                        return JPEGColorSpace.CMYK;
                    }
                }
            default:
                throw new IIOException("Cannot determine source color space");
        }
    }
```
