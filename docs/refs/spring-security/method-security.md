### Activate Method Security with @EnableMethodSecurity

Source: https://github.com/spring-projects/spring-security/blob/7.1.1/docs/modules/ROOT/pages/servlet/authorization/method-security.adoc

Activates method-level authorization in a Spring Security application. Add this annotation to any @Configuration class, or use the XML equivalent. Spring Boot Starter Security does not activate method-level authorization by default.

```java
@EnableMethodSecurity
```

```kotlin
@EnableMethodSecurity
```

```xml
<sec:method-security/>
```

### New @EnableMethodSecurity configuration

Source: https://github.com/spring-projects/spring-security/blob/7.1.1/docs/modules/ROOT/pages/servlet/authorization/method-security.adoc

New configuration using @EnableMethodSecurity, which activates pre-post annotations by default and uses AuthorizationManager internally. This is functionally equivalent to the old @EnableGlobalMethodSecurity(prePostEnabled = true).

```java
@EnableMethodSecurity
```

```kotlin
@EnableMethodSecurity
```

```xml
<method-security/>
```

### Using isAdmin() to secure a method

Source: https://github.com/spring-projects/spring-security/blob/7.1.1/docs/modules/ROOT/pages/native-image/method-security.adoc

Uses the isAdmin() method inside a @PreAuthorize annotation to secure the hello() method. Requires @EnableMethodSecurity on the configuration class.

```java
@PreAuthorize("principal?.isAdmin()")
public String hello() {
    return "Hello!";
}
```

### Java @PreAuthorize examples

Source: https://github.com/spring-projects/spring-security/blob/7.1.1/docs/modules/ROOT/pages/servlet/authorization/method-security.adoc

Shows @PreAuthorize expressions for method-level authorization in Java, including denyAll, hasRole, hasAuthority, principal claims, and custom bean checks.

```java
@PreAuthorize("denyAll") <1>
    MyResource myDeprecatedMethod(...)

    @PreAuthorize("hasRole('ADMIN')") <2>
    MyResource writeResource(...)

    @PreAuthorize("hasAuthority('db') and hasRole('ADMIN')") <3>
    MyResource deleteResource(...)

    @PreAuthorize("principal.claims['aud'] == 'my-audience'") <4>
    MyResource readResource(...);

	@PreAuthorize("@authz.check(authentication, #root)")
    MyResource shareResource(...);
}
```

### Annotate method with @PreAuthorize in Java

Source: https://github.com/spring-projects/spring-security/blob/7.1.1/docs/modules/ROOT/pages/servlet/authorization/method-security.adoc

Use @PreAuthorize("hasRole('ADMIN')") to restrict method invocation to users with the ROLE_ADMIN authority. The method is only invoked if the SpEL expression passes.

```java
@Component
public class BankService {
	@PreAuthorize("hasRole('ADMIN')")
	public Account readAccount(Long id) {
        // ... is only invoked if the `Authentication` has the `ROLE_ADMIN` authority
	}
}
```
