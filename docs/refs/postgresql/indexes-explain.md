### 11.2. Index Types

Source: https://www.postgresql.org/docs/18/indexes-types.html

PostgreSQL provides several index types: B-tree, Hash, GiST, SP-GiST, GIN, BRIN, and the extension [bloom](https://www.postgresql.org/docs/18/bloom.html 'F.6. bloom — bloom filter index access method'). Each index type uses a different algorithm that is best suited to different types of indexable clauses. By default, the [`CREATE INDEX`](https://www.postgresql.org/docs/18/sql-createindex.html 'CREATE INDEX') command creates B-tree indexes, which fit the most common situations.
