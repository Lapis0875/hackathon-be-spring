### LOAD DATA INFILE for CSV with ENCLOSED BY and LINES TERMINATED BY

Source: https://dev.mysql.com/doc/refman/8.0/en/load-data.html

Loads a CSV file with fields enclosed in double quotes, comma-separated, lines terminated by carriage return/newline, and an initial header line skipped. Use OPTIONALLY before ENCLOSED BY if values are not always quoted.

```sql
LOAD DATA INFILE 'data.txt' INTO TABLE tbl_name
  FIELDS TERMINATED BY ',' ENCLOSED BY '"'
  LINES TERMINATED BY '\r\n'
  IGNORE 1 LINES;
```

### LOAD DATA INFILE with IGNORE 1 LINES

Source: https://dev.mysql.com/doc/refman/8.0/en/load-data.html

Loads a file while skipping the first line, useful when the file contains a header row. The IGNORE 1 LINES clause tells LOAD DATA to skip the initial line before reading data.

```sql
LOAD DATA INFILE '/tmp/test.txt' INTO TABLE test IGNORE 1 LINES;
```

### Basic INSERT ... ON DUPLICATE KEY UPDATE and equivalent UPDATE

Source: https://dev.mysql.com/doc/refman/8.0/en/insert-on-duplicate.html

Shows the basic syntax of INSERT ... ON DUPLICATE KEY UPDATE and its equivalent UPDATE statement when a UNIQUE column contains a duplicate value. The effects are not identical for InnoDB tables with an auto-increment column: the INSERT increases the auto-increment value, but the UPDATE does not.

```sql
INSERT INTO t1 (a,b,c) VALUES (1,2,3)
  ON DUPLICATE KEY UPDATE c=c+1;
```

```sql
UPDATE t1 SET c=c+1 WHERE a=1;
```

### LOAD DATA INFILE with matching FIELDS TERMINATED BY

Source: https://dev.mysql.com/doc/refman/8.0/en/load-data.html

Reads a comma-delimited file into a table. The FIELDS TERMINATED BY ',' clause must match the option used when the file was written with SELECT ... INTO OUTFILE.

```sql
LOAD DATA INFILE 'data.txt' INTO TABLE table2
  FIELDS TERMINATED BY ',';
```

### Load table data with LOAD DATA INFILE in mysql client

Source: https://dev.mysql.com/doc/refman/8.0/en/reloading-delimited-text-dumps.html

Alternative to mysqlimport: use the LOAD DATA statement from within the mysql client to load the data file into the table.

```sql
mysql> USE db1;
mysql> LOAD DATA INFILE 't1.txt' INTO TABLE t1;
```
