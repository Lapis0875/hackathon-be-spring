### JSON_VALUE(json_doc, path [RETURNING type] [ON EMPTY] [ON ERROR])

Source: https://dev.mysql.com/doc/refman/8.0/en/json-search-functions.html

```APIDOC
## JSON_VALUE(json_doc, path [RETURNING type] [ON EMPTY] [ON ERROR])

### Description
Extracts a value from a JSON document at the specified path and returns it as the specified SQL type. Supports ON EMPTY and ON ERROR clauses for handling missing data or conversion errors.

### Syntax
```sql
JSON_VALUE(json_doc, path [RETURNING type] [ON EMPTY {NULL | DEFAULT value | ERROR} ON ERROR {NULL | DEFAULT value | ERROR}])
```

### Parameters
- **json_doc** (JSON) - Required - The source JSON document.
- **path** (string) - Required - The JSON path to the value to extract.
- **RETURNING type** - Optional - The SQL data type to cast the result to.
- **ON EMPTY** - Optional - Specifies behavior when the path does not match any data. Must precede ON ERROR.
- **ON ERROR** - Optional - Specifies behavior when an error occurs. Default is NULL ON ERROR.

### ON EMPTY / ON ERROR Values
- `NULL ON ERROR` - Returns NULL (default).
- `DEFAULT value ON ERROR` - Returns the specified value.
- `ERROR ON ERROR` - Throws an error.

### Error Handling
- Invalid JSON input throws an SQL error without triggering ON ERROR.
- ON ERROR triggers on: extracting an object/array, conversion errors, truncation.
- Conversion errors always trigger a warning even with NULL or DEFAULT ON ERROR.
- ON EMPTY triggers when the path contains no data.

### Request Example
```sql
SELECT JSON_VALUE('{"fname": "Joe", "lname": "Palmer"}', '$.fname');
```

```

### Solution 1: Index JSON value with COLLATE utf8mb4_bin

Source: https://dev.mysql.com/doc/refman/8.0/en/create-index.html

Assigns the indexed expression the same collation as JSON_UNQUOTE() (utf8mb4_bin) to make the index usable. The comparison is case-sensitive, so only one row matches. Includes table creation, data insertion, and the query.

```sql
CREATE TABLE employees (
  data JSON,
  INDEX idx ((CAST(data->>"$.name" AS CHAR(30)) COLLATE utf8mb4_bin))
);
INSERT INTO employees VALUES
  ('{ "name": "james", "salary": 9000 }'),
  ('{ "name": "James", "salary": 10000 }'),
  ('{ "name": "Mary", "salary": 12000 }'),
  ('{ "name": "Peter", "salary": 8000 }');
SELECT * FROM employees WHERE data->>'$.name' = 'James';
```

+------------------------------------+

+------------------------------------+
| {"name": "James", "salary": 10000} |
+------------------------------------+
```

### Create multi-valued index with CREATE TABLE

Source: https://dev.mysql.com/doc/refman/8.0/en/create-index.html

Creates a table with a multi-valued index on a JSON array column using CAST(... AS ... ARRAY). The index is defined inline in the CREATE TABLE statement.

```sql
CREATE TABLE customers (
    id BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
    modified DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    custinfo JSON,
    INDEX zips( (CAST(custinfo->'$.zipcode' AS UNSIGNED ARRAY)) )
    );
```
